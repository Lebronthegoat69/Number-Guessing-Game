# Number Guessing Game

## Description
This Java console program is a number guessing game. The computer randomly chooses a number between 1 and 100, and the user keeps guessing until they find the correct number. The program tells the user if each guess is too high, too low, or correct and counts the number of attempts.

## How to Run
1. Open the project in IntelliJ IDEA.
2. Open `Main.java`.
3. Run the `Main` class.
4. Enter guesses between 1 and 100.

## Example Output
